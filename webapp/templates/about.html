About This Project

🎯 Project Overview

This is a BTech Final Year Project for CSE-AIML students. The project aims to build an intelligent system that can identify medicinal plants from leaf images using deep learning techniques and provide information about their medicinal uses.

🔬 Technical Details

  • Model Architecture: MobileNetV2 with Transfer Learning
  • Framework: TensorFlow/Keras
  • Training Data: ~500-1000 leaf images per plant species
  • Input Size: 224×224 RGB images
  • Plant Classes: Aloevera, Bhrami, Neem, Tulsi, Turmeric

🌱 Supported Medicinal Plants

  • Aloevera: Skin burns, wounds, digestive health
  • Bhrami: Memory enhancement, cognitive improvement
  • Neem: Skin health, antibacterial properties
  • Tulsi: Cough relief, respiratory health
  • Turmeric: Anti-inflammatory, antioxidant properties

💻 Technology Stack

  • Backend: Flask, Python
  • Machine Learning: TensorFlow, Keras, scikit-learn
  • Frontend: HTML5, CSS3, JavaScript
  • Data Processing: NumPy, Pandas, OpenCV

📊 Model Performance

The model achieves high accuracy in identifying medicinal plants from leaf images. The system uses confidence thresholds to ensure reliable predictions and can fall back to showing all predictions if confidence is low.

🚀 How to Use

  1. Upload a clear image of a plant leaf
  2. The system will analyze the leaf characteristics
  3. View the identified plant name and confidence level
  4. Learn about the medicinal uses and health benefits

⚠️ Disclaimer

This tool is for educational and informational purposes only. The predictions are based on machine learning models and may not always be 100% accurate. Always consult with healthcare professionals before using any medicinal plant for health purposes.
