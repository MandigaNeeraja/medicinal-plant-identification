# Medicinal Plant Identification - Project Guide

## Overview
This is a complete end-to-end machine learning project to identify medicinal plants from leaf images and display their names and medicinal uses.

## Technology Stack
- **Backend**: Python, Flask/FastAPI
- **ML**: TensorFlow/Keras, OpenCV
- **Frontend**: HTML5, CSS3, JavaScript
- **Data**: NumPy, Pandas, Scikit-learn
- **Visualization**: Matplotlib, Seaborn

## Dataset Information
- **Classes**: Aloevera, Bhrami, Neem, Tulsi, Turmeric (5 medicinal plants)
