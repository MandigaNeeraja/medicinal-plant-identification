# Render Deployment Guide

## Architecture on Render

| Service | Type | URL |
|---------|------|-----|
| `medicinal-plant-api` | Python Web Service | `https://medicinal-plant-api.onrender.com` |
| `medicinal-plant-frontend` | Static Site | `https://medicinal-plant-frontend.onrender.com` |
| `medicinal-plant-db` | PostgreSQL | Internal connection |

## Prerequisites

1. GitHub account with this repo pushed
2. [Render account](https://render.com) (free tier works)
3. Your `GROQ_API_KEY` from https://console.groq.com/keys

## Deploy steps

### 1. Push code to GitHub

```bash
git push origin development
```

### 2. Create Blueprint on Render

1. Go to https://dashboard.render.com/
2. Click **New** → **Blueprint**
3. Connect your GitHub repo
4. Render detects `render.yaml` automatically
5. Click **Apply**

### 3. Set secret environment variables

After the blueprint is created, open the **medicinal-plant-api** service → **Environment**:

| Variable | Value |
|----------|-------|
| `GROQ_API_KEY` | Your Groq API key |
| `GOOGLE_CLIENT_ID` | (optional) Google OAuth client ID |
| `GOOGLE_CLIENT_SECRET` | (optional) Google OAuth secret |

`SECRET_KEY` and `JWT_SECRET_KEY` are auto-generated by the blueprint.

### 4. Wait for deploy

- **API** build takes 5–15 min (TensorFlow is large)
- **Frontend** build takes ~1–2 min
- **Database** is provisioned automatically

### 5. Verify

1. Open `https://medicinal-plant-frontend.onrender.com`
2. Register a new account
3. Upload a leaf image on **Identify**
4. Test AI chat

API health check: `https://medicinal-plant-api.onrender.com/api/health`

## Google OAuth (optional)

In Google Cloud Console, add this authorized redirect URI:

```
https://medicinal-plant-api.onrender.com/api/auth/google/callback
```

## Notes

- Free tier API sleeps after 15 min inactivity — first request may take ~30s to wake up
- Model files in `models/` must be committed to Git for Render to use them
- PostgreSQL persists user data; SQLite is not used in production
- Uploads on Render free tier are ephemeral (lost on redeploy) — upgrade for persistent disk

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Build timeout | Upgrade to paid plan or reduce TensorFlow deps |
| CORS error | Check `CORS_ORIGINS` matches frontend URL exactly |
| Login cookies not working | Ensure `JWT_COOKIE_SECURE=true` and frontend uses HTTPS |
| 503 on predict | Model files missing — verify `models/best_model.h5` is in repo |
